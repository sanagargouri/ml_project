# ML Project

Machine Learning project developed with Python.

## Environment

The project uses a Python virtual environment (`venv`) and the following main libraries:

- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Jupyter
- MLflow
- FastAPI
- Uvicorn
- Joblib

## Installation

Create and activate the virtual environment:

```bash
virtualenv venv
source venv/bin/activate
